qr-code-forge

A QR code encoder and decoder built from scratch — GF(256) Reed-Solomon, ISO/IEC 18004 module placement, all running client-side in this page.

Decoded by this library's own decoder (not a photo scanner) — reading the modules back, correcting any simulated damage, and reassembling the text.
Encode something to see it decoded here.
Everything on this page runs from demo/qrcode.bundle.js, a plain concatenation of the CommonJS modules in /src (see tools/build-bundle.js). No dependencies, no build step.
